Connect your board

Tasks are saved in your team's Supabase project, so everyone sees the same board, live.

  1. Create a free project at supabase.com.
  2. Open SQL Editor, paste the contents of schema.sql and click Run.
  3. Go to Project Settings → API and copy the Project URL and the publishable (anon) key.

Never paste the service_role / secret key here — only the publishable one.
